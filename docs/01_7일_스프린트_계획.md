## Day 1 결과 요약 (오늘)

- **데이터 선정 확정**: Multi-pose Dog Dataset(MPDD) 단일 데이터셋으로 진행.
  근거는 [`notebooks/01_eda.ipynb`](../notebooks/01_eda.ipynb) 참고.
- **EDA 핵심 발견**
  - 191개체 / 1,657장, train(95 ID)·test(96 ID) 분리된 올바른 open-set 분할.
  - 짧은 변 128px 미만 이미지가 **30.6%**, 64px 미만도 3.1% → 저해상도 대응 필수.
  - 실제로 목줄·거리·마당 등 **한국 실외 환경에서 찍힌 믹스견 비중이 높음** → animal.go.kr과의
    도메인 갭이 걱정했던 것보다 작을 가능성. 품종은 순종 라벨보다 "믹스" 취급이 현실적.
  - 같은 개체도 자세·구도 변화가 커서 포즈 강건 임베딩이 필요하다는 가설을 데이터로 확인.

## D1.5 — animal.go.kr 실 데이터 확보 (예정보다 앞당김)

data.go.kr 개발계정이 자동 승인되어 예상보다 빨리 진행했다. `scripts/fetch_shelter_api.py`로 수집.

- **최근 60일, 공고중(보호중) 상태인 유기견 1,464건**, 사진 2,899장 다운로드 (892MB, `Data/shelter/`)
- 다운로드 실패율 <1% (37/2,936 URL, 대부분 만료된 이미지 링크)
- **믹스견 1,197건 (81.8%)** — 순종은 푸들·말티즈·포메라니안·진도견 순으로 소수.
  → 지난 논의에서 예상한 대로 "품종 하드 필터는 위험, 소프트 신호로만" 결정이 실제 수치로 확인됨.
- 표본 사진에서 **눈에 이모지 스티커, 사람 팔, 어수선한 배경**이 확인됨 → MPDD 대비 실제 도메인 갭이
  뚜렷이 존재. 개 탐지·크롭 전처리가 있고 없고의 차이를 반드시 실험으로 비교해야 함.
- 지역 분포는 경기·경남·전남·전북 순으로 전국에 고르게 퍼짐.

**영향**: 데모 갤러리(D5)와 도메인 테스트(원래 스트레치였던 E9)를 지금 데이터로 바로 할 수 있게 됐다.
단, 시간 예산은 그대로 D2~D4(핵심 임베딩 모델)에 우선 배정하고, 이 데이터는 D5 데모에 붙이는 정도로
쓴다 — 실제 도메인 사진으로 별도 임베딩 모델을 다시 학습하지는 않는다(7일 예산 안에서는 과함).
