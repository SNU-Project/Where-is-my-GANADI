# 7일 스프린트 계획 (2026-09-13 확정)

> 기존 8주 기획서(`00_기획서.md`)는 이상적 풀스코프 설계다.
> 마감이 **7일**로 확정되어, EDA 결과를 바탕으로 스코프를 재조정한다. 이 문서가 우선한다.

## Day 1 결과 요약 (오늘)

- **데이터 선정 확정**: Multi-pose Dog Dataset(MPDD) 단일 데이터셋으로 진행.
  근거는 [`notebooks/01_eda.ipynb`](../notebooks/01_eda.ipynb) 참고.
- **EDA 핵심 발견**
  - 191개체 / 1,657장, train(95 ID)·test(96 ID) 분리된 올바른 open-set 분할.
  - 짧은 변 128px 미만 이미지가 **30.6%**, 64px 미만도 3.1% → 저해상도 대응 필수.
  - 실제로 목줄·거리·마당 등 **한국 실외 환경에서 찍힌 믹스견 비중이 높음** → animal.go.kr과의
    도메인 갭이 걱정했던 것보다 작을 가능성. 품종은 순종 라벨보다 "믹스" 취급이 현실적.
  - 같은 개체도 자세·구도 변화가 커서 포즈 강건 임베딩이 필요하다는 가설을 데이터로 확인.

## 스코프 컷 (풀 기획서 대비)

| 컷 항목 | 사유 |
|---|---|
| PetFace 사전학습 | 신청/약관 확인 지연 리스크 → **제외**, ImageNet 사전학습만 사용 |
| 품종 분류기 정식 학습 | 시간 부족 → **제외**. 필요하면 timm 사전학습 분류기 추론값만 참고 |
| 백본/손실 비교 E0~E9 전체 | 9개 실험 불가능 → **4개로 축소** (아래 표) |
| animal.go.kr 실 갤러리 API 연동 | API 키 발급 지연 리스크 → **제외**, 수동 캡처 5~10장으로 데모만 |
| k-reciprocal 재순위, 품종 재순위 | 시간 남으면 스트레치, 필수 아님 |

## 축소된 실험 매트릭스

| # | 내용 | 목적 |
|---|---|---|
| E0 | ImageNet 사전학습 ResNet50 feature, 학습 없이 cosine kNN | 베이스라인 |
| E1 | ResNet50 + BNNeck + CrossEntropy 파인튜닝 | 파인튜닝 효과 |
| E2 | E1 + Triplet loss (hard mining) | 메트릭 러닝 효과 |
| E3 (스트레치) | 저해상도 증강 추가 학습 | 실사용 도메인 대응 |

지표: CMC Rank-1/Rank-5/Rank-10, mAP.
