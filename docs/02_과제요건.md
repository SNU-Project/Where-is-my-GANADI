## Task 정의
"딥러닝 모델(CNN, RNN, LSTM, Transformer, LLM, LMM 등 강의 범위 내)을 활용한 자유 주제."
→ 우리는 **CNN 기반 임베딩(ResNet50) + 메트릭러닝/메타러닝**으로 구조화. 전이학습(pretrained
모델을 가져와 우리 데이터로 튜닝)이 안내문에 명시적으로 허용됨:
> "HuggingFace에서 모델을 가져와서 수행하는 프로젝트에 맞게 튜닝하는 방식도 가능 (transfer)"

## 발표 구성 요건 → 우리 프로젝트 매핑

| 요건 | 우리 프로젝트에서 해당하는 부분 |
|---|---|
| 주제 선택 이유, 모델 활용방안 | `00_기획서.md` 1~2절 (문제 정의: 왜 분류가 아니라 검색/Re-ID인가) |
| EDA로 데이터 특징 설명 | `notebooks/01_eda.ipynb`, `docs/eda/` |
| 전처리 설명 (결측치/이상치/불균형 등) | 저해상도 이미지 처리, 클래스(개체)당 이미지 수 불균형(DogFaceNet 2~41장) 대응 — D3에서 구현·문서화 예정 |
| DL 모델 이론적 배경, 선택 이유 | ResNet50 백본 + BNNeck/CE(E1), Prototypical Network(E2) 이론 설명 — 보고서에 포함 예정 |
| loss, hyperparameter 설명 | E1: CrossEntropy / E2: Prototypical loss, 학습률 등 — D3~D4에서 확정 |
| 평가 방식·지표 설명 | CMC Rank-1/5/10, mAP (`src/retrieval/metrics.py`) |
| **baseline vs DL 모델 비교 (가산점)** | **E0(학습 없음) vs E1 vs E2 비교표 — 이미 이렇게 설계되어 있음** |
| 결과 해석, 무엇이 잘 되고 안 됐는지, 데이터 특징과의 연관 | D4 정성분석 (실패 사례, Grad-CAM), 도메인 갭(animal.go.kr) 논의 |
